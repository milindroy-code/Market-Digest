# Market-Digest — The Opening Bell

A daily and weekly digest of the most important Indian stock market news,
published as a static site and deployed to Vercel.

- `site/` — the deployed static site (daily edition, weekly edition, archive)
- `digest.html`, `digests/` — the original one-off Claude Artifact + markdown archive
- `DIGEST-PLAYBOOK.md` — the content structure and sources every edition follows

Live site: https://opening-bell-sandy.vercel.app
